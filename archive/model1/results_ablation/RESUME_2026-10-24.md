## Bugs fixed today (committed)

- `06_train_lightgbm.py`: Arrow pool released every 10 chunks; ensemble passes
  2..N no longer re-allocate the 4.4 GB join-key arrays (`want_keys=False`).
  Without this the run thrashed at ~10 GB and throughput fell 30×.
- `06_train_lightgbm.py`: `ck_sig_of()` hashed `repr(Booster)` and so embedded an
  object address; checkpoints were rejected on every process start and two
  completed passes were discarded. Now hashes the model text.
- `run_infra_ablation.ps1`: `Log()` used `Write-Output` inside a function, so a
  failed arm returned an array and the abort check never fired; failures now
  throw. Preflight refuses to start on the 484M-row `features_train.parquet`.
